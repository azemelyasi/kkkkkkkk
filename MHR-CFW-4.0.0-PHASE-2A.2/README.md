# MHR CFW 3.0.0 — Windows 11 Python Edition

Python launcher around the MHR 2.0.0 relay engine with Windows system-proxy management and an optional official sing-box TUN sidecar. See `README_FA.md` for setup, limitations, and security details.

Run `run.bat`. Configure your own Apps Script and Cloudflare Worker deployment; no credentials are bundled.
